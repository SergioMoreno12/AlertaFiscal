# Dataset Card: AlertaFiscal Monthly Series (Phase 2)

- **Owner:** Samuel Castellanos Rivera
- **Branch:** `phase2/data-preparation`
- **Version:** November 2026, seed 42

## 1. Purpose
Train and evaluate models that forecast the monthly income and expenses of small businesses, as input for fiscal planning in the AlertaFiscal ERP.

## 2. Intended use
- Training, validating and testing forecasting models for a university course project.
- Demonstrating the ERP forecast module with demo companies.

## 3. NOT for use
- Making real tax, accounting or business decisions.
- Describing any real company. No row is the real monthly record of a real company.
- Publishing results as if they came from real small-business data.

## 4. Contents
| File | What it is | Model input? |
|---|---|---|
| `monthly_series.csv` | 500 companies × 36 months (`2023-01` to `2025-12`): `company_id`, `sector`, `month`, `income`, `expenses`, `origin` (millions of COP) | Yes |
| `split_manifest.csv` | Marks each row as `train`, `validation`, `test` or `holdout` | Yes |
| `sector_profiles.csv`, `seasonality.csv`, `companies_base.csv` | Intermediate statistics used by the generator | No |
| `company_profiles.csv` | The true hidden parameters of each company (margin, growth, size, noise, level shifts) | **Never** (using it is data leakage) |

## 5. Provenance
- **Supersociedades, "10,000 largest companies":** annual company figures published as open data on datos.gov.co (dataset `6cat-2gcs`). Used only to compute sector margins, real year-over-year growth and size ranks.
- **DIAN, monthly tax collection statistics:** public statistics. Used only for the shape of the yearly seasonality (VAT collection). The raw Excel file is **not redistributed** in this repository.
- Raw files and their SHA-256 hashes are listed in `docs/02_run_log.md`.

## 6. How it was generated
Monthly values are generated by a program (`ml/src/generate_series.py`) calibrated with the real statistics above. 60% of the companies are `derived` (their profile comes from a real Supersociedades record) and 40% are `simulated` (profile sampled from sector distributions). Every company is rescaled to small-business size. The full method and every parameter are in `docs/02_dataset_report.md`.

## 7. Known limitations
- Monthly values are generated, not observed.
- Margins come from large companies, so small businesses may differ.
- One national seasonal shape is used for all sectors.
- About 30% of company-months show a loss because real margins are thin.
- 72 companies have a permanent level shift that no model can predict.
- Only 36 months of history.

## 8. Privacy
- No personal data.
- Real tax ids (NIT) are **not** written to any output file. Real records are referenced only by an anonymous `record_id`.
- `company_id` values (`C0001` to `C0500`) are random labels with no link to a real company.

## 9. Reproducibility
Run the four scripts in `ml/README.md`. With the same raw files, the same package versions and seed 42, the output is identical. Verification: `ml/src/check_dataset.py` (26 checks) and `docs/02_run_log.md`.
